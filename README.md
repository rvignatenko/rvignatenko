## Роман Игнатенко

Трекер и ментор. Веду команды в акселерационных программах — от диагностической
сессии до первых сделок. Работаю по методологии Школы менторов МИК: ключевое
ограничение, снятие запроса, GROW, HADI-циклы.

Параллельно собираю инструменты, которые эту работу держат: чтобы методика не
жила в голове, а расшифровки, дневники и обещания организаторов не терялись между
встречами. Что оказалось полезно не только мне — выкладываю сюда.

### Что открыто

**[treker-akseleratora](https://github.com/rvignatenko/treker-akseleratora)** —
работа трекера в акселераторе с любым числом потоков и команд. Методика,
шаблоны документов и пять инструментов: развёртывание проекта под программу,
готовность к встрече, раскладка папки команды, расшифровка записей, контроль
того, ведёт ли команда свой дневник.

Собрано по итогам живого трека: четыре команды, два отраслевых потока,
двенадцать недель. Внутри нет данных ни одной конкретной программы — всё
задаётся при развёртывании.

git clone https://github.com/rvignatenko/treker-akseleratora.git \
